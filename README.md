# VK Bot для Tower of Random

Бот-помощник для игры Tower of Random во ВКонтакте.

## Возможности

- 📊 Анализ профиля персонажа и доступных классов
- 🏰 Подсчёт лута и ресурсов из Башни
- 📝 Управление заметками
- 💾 Автоматические бэкапы базы данных
- 🛡️ Rate limiting и валидация входных данных
